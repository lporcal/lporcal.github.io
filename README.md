lporcal.github.io — Portfolio de Lucas Porcal

Portfolio personal desarrollado como parte de mi transición de carrera desde Ingeniería de Procesos hacia roles de Análisis de Datos / desarrollo web. Funciona como centro de referencia para reclutadores: combina proyectos de análisis de datos, proyectos de ingeniería industrial (documentados sin datos propietarios) y mi trayectoria profesional.

🔗 Sitio en vivo: lporcal.github.io


Sobre este proyecto

Soy Ingeniero Químico con más de 13 años de experiencia industrial en procesamiento de aceites, grasas y biocombustibles. Este sitio nació como trabajo práctico de una capacitación en programación web y se convirtió en mi portfolio profesional activo mientras me formo como Data Analyst.

Stack técnico


HTML / CSS / JavaScript puro (sin frameworks ni build tools)
Bootstrap 5 para el sistema de grillas y componentes de navegación
Font Awesome para iconografía
EmailJS para el formulario de contacto (sin backend propio)
Google Analytics 4 para métricas de tráfico
GitHub Pages para hosting y despliegue continuo


Estructura del proyecto

├── index.html                          # Página principal
├── pages/
│   ├── acercade/                       # Sección "Acerca de mí"
│   ├── proyectos/                      # Catálogo de proyectos
│   ├── experiencia/                    # Trayectoria profesional
│   ├── licenciasycertificaciones/      # Certificaciones
│   ├── publicaciones/                  # Publicaciones y posts
│   └── formularios/                    # Formulario de contacto
├── estilos.proyecto.css                # Hoja de estilos compartida
├── programa.proyectofinal.js           # JS compartido entre páginas
└── docs/                               # CV descargable en PDF

Características principales


Navegación por anclas y sistema de rutas entre páginas
Formulario de contacto funcional vía EmailJS (sin exponer backend)
Seguimiento de tráfico con GA4, incluyendo esquema de UTM para distinguir origen de visitas (LinkedIn, CV, certificados, etc.)
Diseño responsive con CSS Grid para tarjetas de proyectos y certificaciones
SVG animado en el hero de la página principal


Nota sobre proyectos industriales

Algunos proyectos mostrados en el sitio están basados en mi experiencia en empresas anteriores. Por razones de confidencialidad, estos se presentan sin datos propietarios ni información sensible de esas organizaciones — únicamente se documentan el enfoque metodológico y los resultados generales del proceso.
