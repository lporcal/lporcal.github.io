Proyectos | Análisis de Datos | Programa Check List de Maniobras

Automatización de generación de check lists operativos mediante lógica programada (Excel + VBA)
Desarrollo de una herramienta automatizada para la generación de check lists operativos en formato PDF, orientada a la estandarización de maniobras en planta y reducción de errores humanos.
Contexto

Las maniobras operativas de transferencia de producto dentro de la planta se realizan mediante colectores equipados con válvulas manuales, conectando distintas líneas de producción, etapas de proceso y tanques de almacenamiento. La operación simultánea de múltiples productos, junto con restricciones de compatibilidad entre productos, tanques y procesos, genera miles de configuraciones posibles de maniobra.

La instalación cuenta con cuatro colectores principales (A, B, C y D), múltiples líneas de producción y diferentes configuraciones operativas según el producto procesado. Cada maniobra requiere la apertura y cierre correcto de numerosas válvulas manuales, donde un error operativo puede provocar contaminación de producto, mezclas no deseadas, pérdidas económicas y desvíos de calidad.

Debido a la complejidad operativa y a la gran cantidad de combinaciones posibles, surgió la necesidad de desarrollar una herramienta que permitiera estandarizar las maniobras, reducir errores humanos, mejorar la trazabilidad operativa y automatizar la generación de instructivos/check lists para el personal de planta.

Objetivo

Generar automáticamente listas de verificación (check lists) de maniobras para la apertura y cierre de válvulas manuales, permitiendo al operador obtener las acciones requeridas para realizar movimientos de producto a partir del ingreso de distintas variables del proceso en un programa.

Herramientas
  • Excel
  • Microsoft Visual Basic
Presentación
  • • Diseño de lógica de decisión basada en inputs del usuario (origen, destino, tipo de maniobra)
  • • Implementación de cálculos y reglas mediante funciones avanzadas de Excel (BUSCARV, SI, SUMAR.SI.CONJUNTO, etc)
  • • Programación de macros en VBA para automatización de procesos y generación de reportes en PDF
  • • Definición automática de configuración de válvulas manuales según condiciones operativas
  • • Diseño de estructura flexible y escalable para incorporación de nuevas líneas de proceso y configuraciones sin modificar el código base
  • • Generación automática de registros operativos para trazabilidad de maniobras
Resultados de su aplicación

Reducción en un 100% de errores operativos, mejora en la seguridad del proceso y estandarización de procedimientos
