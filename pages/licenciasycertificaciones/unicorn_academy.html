Bootcamp Análisis de Datos
Unicorn Academy

Bootcamp intensivo en Análisis de Datos orientado al desarrollo de habilidades técnicas y de negocio para la toma de decisiones basada en datos. La formación incluyó herramientas como Google Sheets, SQL, Power BI y Python, aplicadas a proyectos reales y casos prácticos de análisis, visualización y automatización de datos.

El programa combinó contenido técnico, resolución de problemas reales y desarrollo profesional, incluyendo construcción de portfolio, optimización de perfil de LinkedIn y enfoque en comunicación de insights. La modalidad práctica y aplicada me permitió fortalecer mi pensamiento analítico, mejorar mi capacidad para interpretar datos y complementar mi experiencia en ingeniería de procesos con herramientas modernas de análisis de datos y Business Intelligence.

Temario Completo

Bootcamp completo de 8 meses, de modalidad part time, que te enseña las habilidades que demandan las empresas en análisis de datos.

Combina contenido teórico grabado, sesiones en vivo y proyectos prácticos junto a los docentes. Finalizamos con la entrega de un proyecto final integrador.

Módulo 1: Introducción al mundo del analista de datos

Duración: 1 Semana | Total Horas: 5 Horas.

• Este modulo explica los conceptos básicos del mundo del análisis de datos como base para la posterior comprensión de las herramientas.

  • ✓ ¿Qué es el análisis de datos?
  • ✓ Fuentes de datos
  • ✓ Conceptos importantes del mundo de análisis de datos
  • ✓ Como trabaja un analista de datos

Módulo 2: Google Sheets

Duración: 3 Semanas | Total Horas: 20 Horas | 1 Proyecto Práctico.

• En este modulo se explican los conceptos y herramientas básicas que necesitas saber de Google Sheets para manipular y trabajar con datos. Desde funciones, tablas dinámicas hasta gráficos y automatización de reportes.

  • ✓ Fundamentos
  • ✓ Habilidades básicas
  • ✓ Fórmulas y funciones
  • ✓ Tablas dinámicas
  • ✓ Importación y exportación de datos
  • ✓ Colaboración y compartir
  • ✓ Limpieza de datos
  • ✓ Gráficos y Visualizaciones de datos

Módulo 3: Business Intelligence con Power BI

Duración: 5 Semanas |Total Horas: 30 Horas | 2 Proyectos Prácticos.

• Este módulo abarca desde la instalación de Power BI hasta el manejo de entornos de trabajo y vistas. Aprendimos Power Query, para adquirir y transformar datos de varias fuentes, incluyendo tratamientos avanzados como la agregación. Como crear modelos dimensionales efectivos, aprovechando conceptos clave como granularidad y jerarquías. Continuamos con una introducción a DAX, dominando las funciones de agregación e iteración, aplicando cálculos y medidas.

  • ✓ Importación de datos
  • ✓ Transformación de datos
  • ✓ Modelado de datos
  • ✓ Lenguaje DAX (Data Analysis Expressions)
  • ✓ Visualización de datos
  • ✓ Creación de informes interactivos
  • ✓ Paneles de control (dashboards)
  • ✓ Publicación y distribución de informes
  • ✓ Seguridad y administración
  • ✓ Análisis y toma de decisiones

Módulo 4: Bases de datos con SQL

Duración:5 Semanas | Total Horas:30 Horas | 2 Proyectos Prácticos.

• En éste módulo de SQL, se adquieren conocimientos esenciales para interactuar y gestionar bases de datos. Desde la creación de bases de datos, consulta y filtrado avanzado de datos, optimización de consultas y modelado de datos, junto con el uso de funciones agregadas y técnicas de análisis exploratorio.

  • ✓ Fundamentos de SQL
  • ✓ Filtros y Condiciones
  • ✓ Funciones de Agregación
  • ✓ Join y Relaciones entre Tablas
  • ✓ Subconsultas
  • ✓ Limpieza de datos
  • ✓ Análisis Avanzado y Ventanas (Window Functions)

Módulo 5: Análisis de datos y estadística con Python

Duración: 10 Semanas | Total Horas: 60 Horas | 3 Proyectos Prácticos.

• En éste módulo partimos desde cero, explorando tipos de objetos, lógica condicional, bucles y funciones, entre otros aspectos. Se aprende cómo adquirir datos de fuentes y formatos, y a manipularlos eficazmente utilizando la librería Pandas. Desde la limpieza de datos hasta una introducción esencial a la visualización orientada a la exploración y el análisis. Se termina el módulo con conceptos claves de estadística descriptiva y técnicas para comprender las relaciones entre variables.

  • ✓ Fundamentos de Programación
  • ✓ Introducción a Python
  • ✓ Funciones
  • ✓ Limpieza de datos con Python
  • ✓ Libreria NumPy para operaciones matemáticas
  • ✓ Libreria para manipulación de datos Pandas
  • ✓ Libreria Matplotlib para la creación de gráficos y visualización de datos.
  • ✓ Librería Seaborn para la creación de gráficos estadísticos.

Módulo 6: Fundamentos Cloud

Duración: 3 Semanas | Total Horas: 20 Horas | 1 Proyecto Práctico.

• En éste módulo se aprenden los conceptos esenciales del cómputo en la nube de la mano de la tecnología de Amazon.

  • ✓ Entornos OLTP/OLAP y evolución hacia ecosistemas modernos (Datawarehouse, Big Data y Cloud).
  • ✓ Conceptos base de la nube (CAPEX/OPEX), configuración y diseño de arquitecturas (Lakehouse, Data Mesh y Medallion).
  • ✓ Creación de pipelines y monitorización del ciclo de vida mediante triggers, operadores y observabilidad.

Módulo 7: Proyecto Integrador Final

Duración: 3 Semanas | Total Horas: 40 Horas | 1 Proyecto Práctico Integrador Final

• Aplicarán de manera autónoma los conocimientos adquiridos durante los módulos del bootcamp.
